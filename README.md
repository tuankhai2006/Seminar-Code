# CS163 Seminar Project

This project contains implementations in both C++ and Python for analyzing graphs to find articulation points and bridges.

---

## 📁 Folder Structure

- /C++/ — C++ implementation
- /Python/ — Python implementation

---

## 🔧 Instructions

### C++ Version (/C++/)

1. Save the code in a file named graph.cpp.
2. Open a terminal and navigate to the directory containing graph.cpp.
3. Compile the code using a C++ compiler (e.g, g++): g++ graph.cpp -o graph.
4. Run the executable: ./graph (on Linux/Mac) or graph.exe (on Windows).
5. The program will prompt you to enter the number of vertices (V) and the number of edges
(E).
6. For each edge, enter two integers u and v (separated by a space) to specify an edge between
vertices u and v. Use 0-based indexing (i.e., vertex indices should be in the range [0, V-1]).
7. The program will output the articulation points and bridges for the graph you specified.


### Python Version (/Python/)

1. Save the Python code in a file named graph.py.
2. Open a terminal and navigate to the directory containing graph.py.
3. Ensure Python 3 is installed on your system.
4. Run the script using: python3 graph.py (or python graph.py depending on your system
setup).
5. The program will prompt you to enter the number of vertices (V) and the number of edges
(E).
6. For each edge, enter two integers u and v (separated by a space) to specify an edge between
vertices u and v. Use 0-based indexing (i.e., vertex indices should be in the range [0, V-1]).
7. The program will output the articulation points and bridges for the graph you specified.
